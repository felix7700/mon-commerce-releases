# Mon Commerce – Releases

This repository only distributes signed Android releases of Mon Commerce
(APK files and `update.json` for the in-app update). It contains no source
code and no data.

Each APK is signed with the Mon Commerce release certificate
(SHA-256 `9c06d2f9c6c830685716dba40205f2ae2c2399d64df4cdeb01c14a02e27c12df`).
The app checks this certificate before it offers an update for installation.
